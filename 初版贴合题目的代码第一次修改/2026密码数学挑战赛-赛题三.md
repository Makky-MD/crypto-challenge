# 三、密码学背景及相关问题的研究进展

# 3.1 线性分析的基本逻辑

分组密码算法的安全性来源于持续不断的安全性分析（cryptanalysis）。区分攻击是分析分组密码算法安全性的基本形式。给定一个函数 $F \colon \mathbb { F } _ { 2 } ^ { n } \to \mathbb { F } _ { 2 } ^ { n }$ ,和一定数量的明文-密文对（pair），一个区分器（distinguisher）是一个统计量。例如，在线性分析中，统计量是以下表达式

$$
c o r _ { F } ( v , u ) = 2 ^ { - n } \sum _ { x \in \mathbb { F } _ { 2 } ^ { n } } ( - 1 ) ^ { u ^ { \top } x \oplus v ^ { \top } F ( x ) }
$$

$c o r _ { F } ( v , u )$ 被称为 $F$ 在输入掩码 $\mathbf { u }$ 、输出掩码 $\mathbf { v }$ 的相关度。当F是$\mathbb { F } _ { 2 } ^ { \mathrm { n } }$ 到 $\mathbb { F } _ { 2 } ^ { \mathrm { n } }$ 的随机置换时， $c o r _ { F } ( v , u )$ 相关的期望值应该为0。因为

$$
u ^ { \intercal } x \oplus v ^ { \intercal } F ( x )
$$

的值为 0 或者 1 的概率是相等的。相反地，当我们可以观察到$c o r _ { F } ( v , u )$ 的期望值明显偏离于0 时， $F$ 就不应该是随机置换（当然，该判断基于一定成功率），在安全性分析模型中， $F$ 将会被判断为目标分组密码算法。所以，线性分析在区分器阶段的核心任务有两个：

1. 对目标算法 $F$ ，寻找输入掩码 $u$ 、输出掩码 $\mathbf { v }$ ，使得 $c o r _ { F } ( v , u )$ 明显大于或者小于0。最理想的情况是，找到的输入掩码 $u$ 、输出掩码 $v$ ，使得 $c o r _ { F } ( v , u )$ 的绝对值为最大。

2. 对目标算法 $F$ 、输入掩码 $u$ 、输出掩码 $v$ ，准确地估计 $c o r _ { F } ( v , u )$ 。

# 3.2 逼近 $c o r _ { F } ( v , u )$

现代分组密码算法都是通过线性组件和非线性组件构造而成，例如，在典型的替换-置换网络（Substitution-Permutation Network）分组密码算法中， $r$ 轮密码算法可以被表示为 $r$ 个轮函数的组合：

$$
E = E _ { r } \circ E _ { r - 1 } \circ \cdots \circ E _ { 1 }
$$

为了计算一个E的输入掩码 $u$ 和输出掩码 $v$ 的相关度 $c o r _ { E } ( v , u )$ ，我们可以使用“相关矩阵”方法。一个函数的相关矩阵被定义为：

定义（相关矩阵）：函数 $F \colon \mathbb { F } _ { 2 } ^ { n } \to \mathbb { F } _ { 2 } ^ { n }$ 的相关矩阵, $M _ { F } \in \mathbb { R } ^ { 2 ^ { n } \times 2 ^ { n } }$ ,定义为

$$
M _ { F } [ v , u ] = c o r _ { F } ( v , u ) _ { \circ }
$$

$E$ 的相关矩阵 $M _ { E }$ 可以根据以下定理通过计算每个轮函数的相关矩阵得到。

定理：一个复合函数， $F = F _ { r } \circ F _ { r - 1 } \circ \cdots \circ F _ { 2 } \circ F _ { 1 }$ ，的相关矩阵满足：

$$
M _ { F } = \ d _ { F _ { r } } \ = M _ { F _ { r - 1 } } { \cdots } \ = M _ { F _ { 1 } } \circ
$$

所以，对于给定的输入掩码 $u$ 和输出掩码 $v$ ， $M _ { F } [ v , u ] = c o r _ { F } ( v , u )$ 可以通过矩阵乘法得到：

$$
c o r _ { F } ( v , u ) = \sum _ { u _ { 0 } , u _ { 1 } , \ldots u _ { r } } \prod _ { 1 \leq i \leq r } M _ { F _ { i } } [ u _ { i } , u _ { i - 1 } ]
$$

定义（线性路线）：上式中， $( u _ { 0 } , u _ { 1 } , . . . , u _ { r } )$ 被称为一条线性路线，线性路线的相关度是一个实数，定义为

$$
\mathbf c o r _ { F } ( u _ { 0 } , u _ { 1 } , . . . , u _ { r } ) = \prod _ { 1 \leq i \leq r } M _ { F _ { i } } [ u _ { i } , u _ { i - 1 } ]
$$

定义（线性壳）：所有以 $u$ 开始， $v$ 结束的线性路线构成一个线性壳。

如果我们可以遍历所有的线性路线，并且将他们的相关度累加，我们可以得到 $c o r _ { F } ( v , u )$ 的精确值。然而，由于每个线性壳中的线性路线数量太多，我们事实上是无法遍历所有线性路线的。为此，我们只好使用一部分相关度最大的线性路线来作为线性壳相关度的逼近，甚至使用一条相关度绝对值最大的路线作为逼近：

$$
a b s ( \ c o r _ { F } ( v , u ) \ ) \approx \ \underset { u _ { 0 } , u _ { 1 } , \ldots u _ { r } } { \operatorname* { m a x } } \ \mathrm { a b s ( } \ \prod _ { 1 \leq i \leq r } M _ { F _ { i } } [ u _ { i } , u _ { i - 1 } ] )
$$

使用单条路线的相关度作为 $c o r _ { F } ( v , u )$ 的近似值，这就是传统线性分析中的常用方法。
